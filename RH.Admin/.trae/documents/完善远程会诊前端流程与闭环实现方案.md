## 工作流集成方案
- 模型设计：使用已有 LogicFlow 设计器定义“远程会诊流程”模板（开始→科室审核→医务科审核→排期→会诊→报告签署→结束）。
- 启动实例：
  - 在“创建会诊”成功后，调用 `startWorkflow(definitionId, { businessId: consultationId, ... })`（`src/api/workflow/instance.ts:10-12`）。
  - 将实例号关联到会诊记录，用于详情页展示。
- 审批联动：
  - 审核弹窗提交时，除调用 `auditConsultation` 外，按节点推进 `auditingWorkflow(instanceId, { approved, comment })`（`src/api/workflow/instance.ts:14-16`）。
- 轨迹展示：
  - 复用会诊“流程轨迹”页签（`src/views/remote-consultation/consultation/index.vue:482-487`），将工作流事件注入时间线（后端统一写入）。
- 关联入口：
  - 在会诊详情中增加“查看工作流实例详情”按钮，跳转工作流实例视图。

## 医疗行业专用场景设计
- 合规与隐私：弹窗与详情页显式展示患者隐私提示与同意收集声明；默认关闭“录制”功能，仅管理员可开启（留出布尔位与后端策略）。
- 角色控制：主持人、专家、观察员的操作权限通过前端权限码与成员角色组合控制；按钮使用 Auth/Perms 包裹。
- 影像/白板：
  - 影像查看：保留在资料包中按类型分类；演示页右侧预留“影像标注区”（静态），后续可接入 DICOM Web Viewer。
  - 白板标注：演示页提供静态白板叠加层，支持简单画笔演示（不接入真实协作）。
- 儿科/产科特性：保留并突出孕周与月龄字段（已在患者快照中实现），在会诊目的与模板中提供科室化词条的占位与字典。
- 应急流程：紧急程度字典驱动（`src/views/remote-consultation/consultation/index.vue:76-79`），在筛选与排期中优先提示并限制可选窗口。

## 权限与安全
- 权限：沿用路由与按钮权限（`src/router/modules/remote.ts:10-14, 20-23, 39-41, 48-50`；`functions` 权限码分配在各视图内）。
- 审计：操作均通过后端记录并展示于轨迹页签；前端仅触发事件与显示。
- 通信：如需在线状态与事件推送，使用 SignalR 封装订阅会诊频道（`src/utils/signalr.ts:9-24`）。

## 数据结构与 API 契约
- 统一响应解包：沿用局部 `unwrap<T>`（`consultation/index.vue:65-70` 等）。
- RC 模块 API 与类型集中于 `src/api/rc/*.ts` 与 `types.ts`，后端补充字段按分页/详情契约扩展。
- 工作流实例参数建议包含：`businessId`（会诊ID）、`currentNode`、`auditor`、`approved`、`comment`、`timestamp`。

## 事件与通知（可选增强）
- 创建/审核/排期/开始/结束/关闭事件：通过 SignalR 推送到参与成员页面；演示页显示在线成员与事件吐司提示。

## 全流程闭环
- 会诊申请与资料打包（患者快照 → 资料包）→ 审核（工作流）→ 排期（会议参数）→ 音视频演示（静态页）→ 协同（附件/成员/白板/影像）→ 报告撰写与签署（`submitReport`/`submitSignReport`）→ 归档与统计（同步任务与数据看板）。

## 迭代里程碑
- 阶段一：完善患者/资料包/会诊页面的校验、字典、权限与提示。
- 阶段二：绑定工作流（创建即启动、审核即推进、详情可查看实例）。
- 阶段三：落地“音视频演示”静态页面与会诊详情跳转入口。
- 阶段四：接入 SignalR 的会诊事件订阅与在线成员展示。
- 阶段五：细化医疗合规与审计展示，准备后续接入 RTC/DICOM。
