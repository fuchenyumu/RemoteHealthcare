# 后端AI提示词模板（.NET8+SqlSugar5+PostgreSQL16）

## 1. 后端架构初始化（基础配置）
```text
【后端架构】区域妇幼保健远程诊疗平台-后端项目初始化（.NET8+SqlSugar5+PostgreSQL16）
技术要求：
1. 项目结构：Controllers（接口）、Services（业务）、Repositories（数据访问）、Models（实体）、Utils（工具）、Configs（配置）、Middleware（中间件）；
2. 集成核心依赖：
   - SqlSugarCore（5.1.4.100）：ORM框架，支持PostgreSQL；
   - Swashbuckle.AspNetCore（6.5.0）：Swagger接口文档；
   - JWT（10.0.0）：用户认证；
   - NLog.Web.AspNetCore（5.3.4）：日志记录；
3. 核心配置：
   - SqlSugar：Configs/SqlSugarConfig.cs，实现数据库连接（从appsettings读连接串）、开发环境自动迁移表；
   - JWT：Utils/JwtHelper.cs，生成Token（含userid/name/role）、验证Token；
   - 全局异常中间件：Middleware/GlobalExceptionMiddleware.cs，统一返回格式ApiResult<T>（code/message/data）；
4. 基础接口：
   - 登录接口：Controllers/AuthController/Login(LoginDto)，校验账号密码（演示阶段用固定账号：admin/123456，doctor/123456）；
   - 用户信息接口：Controllers/UserController/GetCurrentUser()，从Token解析用户信息返回。

请生成：
1. 项目初始化命令脚本（dotnet new + 依赖安装）；
2. SqlSugarConfig.cs、JwtHelper.cs、GlobalExceptionMiddleware.cs；
3. LoginDto、ApiResult.cs、AuthController.cs、UserController.cs完整代码。

【后端服务】区域妇幼保健远程诊疗平台-患者信息接口（.NET8+SqlSugar5+PostgreSQL16）
技术要求：
1. 实体类：Models/Medical/PatientInfo.cs
   - 字段：patient_id（UUID主键）、patient_name（VARCHAR(20)）、id_card（VARCHAR(50)）、phone（VARCHAR(20)）、patient_type（INT，1=孕妇/2=儿童）、gestational_week（INT?）、age（INT?）、create_time（TIMESTAMP）；
   - 特性：[Table("remote-healthcare.patient_info")]，id_card/phone标注[NeedDesensitize]（自定义特性，标识需脱敏）；
2. 数据访问层：Repositories/Medical/PatientRepository.cs
   - 继承BaseRepository<PatientInfo>（含CRUD）；
   - 方法：Task<PatientInfo> GetPatientByIdAsync(Guid patientId)（返回前脱敏id_card/phone）；
   - 方法：Task<string> PackPatientDataAsync(Guid patientId)（返回随机生成的packId，格式“PACK+日期+6位随机数”）；
3. 服务层：Services/Medical/PatientService.cs
   - 注入IPatientRepository；
   - 方法：Task<ApiResult<PatientInfoVo>> GetPatientInfoAsync(Guid patientId)（转换为Vo，隐藏敏感字段）；
   - 方法：Task<ApiResult<string>> PackDataAsync(Guid patientId)（调用Repository打包，返回packId）；
4. 接口层：Controllers/Medical/PatientController.cs
   - 接口1：[HttpGet("get/{patientId}")]，[Authorize(Roles = "Doctor,Admin")]，返回PatientInfoVo；
   - 接口2：[HttpPost("pack/{patientId}")]，[Authorize(Roles = "Doctor")]，返回packId；
   - 演示阶段：接口返回模拟数据（标注“演示数据”），暂不对接真实HIS/PACS。

请生成上述4个文件完整代码，包含脱敏逻辑（id_card前6后4，phone前3后4）、权限控制、Swagger注释。
