## 📋 项目概述

- 前端：Vue3 + PureAdmin + TypeScript + Element Plus
- 后端：.NET8 + SqlSugar + PostgreSQL
- 架构：模块化、事件驱动、后台任务

## 🎯 核心功能实现

### 1. 报告生成流程
```
会诊结束 → 生成报告模板 → 自动填充基础信息
```
- 查询会诊信息、患者信息、会诊成员、附件、时间线
- 生成标准化报告模板
- 支持预览和编辑

### 2. 报告编辑流程
```
保存草稿 → 版本历史记录 → 支持多次修改
```
- 支持保存草稿
- 自动记录版本历史
- 支持查看历史版本

### 3. 签署流程
```
提交签署 → 创建签署流程 → 多专家会签 → 顺序签署
```
- 基于会诊成员自动创建签署流程
- 支持主持人、专家、秘书三种角色
- 严格按照顺序签署
- 支持查看签署进度

### 4. 电子签名
```
手写签名 → CA证书 → 生物识别 → 签名存储
```
- 手写签名：Canvas绘制，支持撤销
- CA证书：PIN码验证
- 生物识别：指纹/面部识别（模拟）
- 签名文件存储和验证

### 5. 报告归档
```
所有签署完成 → 自动归档 → 同步EMR系统
```
- 自动检测签署完成状态
- 后台任务同步至EMR
- 支持重试机制
- 事件通知机制

1. **报告提交** → 发送通知给第一个签署人

3. **所有签署完成** → 通知所有参与者
4. **同步完成** → 归档通知
