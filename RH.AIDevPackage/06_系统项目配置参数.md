# RemoteHealthcare项目配置参数

## 📋 开发环境配置参数

### 1. 基本信息
- **项目名称**：RemoteHealthcare（远程医疗平台）
- **开发模式**：AI-First开发
- **目标用户**：医护人员和患者
- **业务场景**：区域妇幼保健远程诊疗

### 2. 网络配置
| 配置项 | 参数值 | 说明 |
|--------|--------|------|
| 本机IP地址 | 127.0.0.1 | 开发环境本地地址 |
| 前端端口 | 8848 | Vue3开发服务器端口 |
| 后端API端口 | 8828 | .NET8 WebAPI服务端口 |
| 数据库端口 | 6950 | PostgreSQL数据库端口 |
| 数据库密码 | 123456 | 数据库连接密码 |
| 数据库名称 | remotehealthcaredb | PostgreSQL数据库名 |

> **说明**：连接字符串中可使用 `Database=RemoteHealthcareDB`，PostgreSQL 会在未加引号时自动转换为小写，与 `remotehealthcaredb` 等价。

#### 4.5 CORS跨域配置
```csharp
// Program.cs 中的CORS配置
builder.Services.AddCors(options =>
{
    options.AddPolicy("DevelopmentPolicy", policy =>
    {
        policy.WithOrigins(
                "http://127.0.0.1:8848",
                "http://localhost:8848"
              )
              .AllowAnyHeader()
              .AllowAnyMethod()
              .AllowCredentials();
    });
});
```

#### 4.6 Docker Compose配置 (docker-compose.yml)
```yaml
version: '3.8'
services:
  remote-healthcare-db:
    image: postgres:16
    ports:
      - "6950:5432"
    environment:
      POSTGRES_DB: remotehealthcaredb
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: 123456
    volumes:
      - postgres_data:/var/lib/postgresql/data
    networks:
      - remote-healthcare-network

  remote-healthcare-backend:
    build: ./RH.WebApi
    ports:
      - "8828:8080"
    depends_on:
      - remote-healthcare-db
    environment:
      ConnectionStrings__PostgreSQL: Host=remote-healthcare-db;Port=5432;Database=remotehealthcaredb;Username=postgres;Password=123456
    networks:
      - remote-healthcare-network

  remote-healthcare-frontend:
    build: ./RH.Admin
    ports:
      - "8848:80"
    depends_on:
      - remote-healthcare-backend
    networks:
      - remote-healthcare-network

volumes:
  postgres_data:

networks:
  remote-healthcare-network:
    driver: bridge
```

### 6. 安全配置

#### 6.1 JWT配置
- **密钥**：使用32位以上的强密钥
- **过期时间**：2小时
- **签发者**：RemoteHealthcareSystem
- **受众**：RemoteHealthcareClient

#### 6.2 数据库安全
- **端口**：使用非标准端口6950
- **密码**：强密码策略
- **连接池**：最大20个连接
- **SSL**：开发环境可关闭，生产环境必须开启

#### 6.3 医疗数据合规
- **数据脱敏**：身份证号前6后4，手机号前3后4
- **访问控制**：基于角色的权限控制
- **审计日志**：所有关键操作记录
- **加密存储**：敏感字段加密
