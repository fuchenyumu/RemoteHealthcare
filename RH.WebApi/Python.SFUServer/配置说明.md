# Python SFU Server 配置说明

## 快速配置

### 方式 1：使用自动更新脚本（推荐）

```bash
# 在 Python.SFUServer 目录下运行
update-env.bat
```

### 方式 2：手动配置

1. **复制环境变量模板**
   ```bash
   copy env.example .env
   ```

2. **编辑 .env 文件**，添加或修改以下配置：

## 完整配置项说明

### 基础配置
```env
APP_NAME=remote-consultation-sfu
APP_ENV=Development
APP_HOST=0.0.0.0
APP_PORT=8000
LOG_LEVEL=INFO
```

### CORS 配置（重要！）
```env
# 允许的前端域名（JSON 数组格式）
CORS_ORIGINS=["https://192.168.1.113:8848", "https://localhost:8848"]

# 是否允许携带凭证（Cookie、Authorization header）
CORS_ALLOW_CREDENTIALS=true

# 允许的 HTTP 方法
CORS_ALLOW_METHODS=["*"]

# 允许的 HTTP 头
CORS_ALLOW_HEADERS=["*"]
```

**重要提示：**
- `CORS_ORIGINS` 必须使用 **JSON 数组格式**
- IP 地址必须与前端实际地址一致
- 如果前端在不同端口，需要添加对应的地址

### JWT 配置
```env
# JWT 密钥（必须修改为强密码！）
JWT_SECRET_KEY=replace-with-strong-secret

# JWT 签发者
JWT_ISSUER=yinzhixin-healthcare

# JWT 受众
JWT_AUDIENCE=medical-rtc

# JWT 有效期（秒）
JWT_TTL_SECONDS=3600
```

**安全提示：**
- `JWT_SECRET_KEY` 必须替换为 32 位以上的随机字符串
- 生产环境建议使用环境变量或密钥管理服务

### Redis 配置
```env
REDIS_HOST=192.168.1.202
REDIS_PORT=6379
REDIS_USERNAME=
REDIS_PASSWORD=
REDIS_DB=0
REDIS_USE_SSL=false
```

### 会议室配置
```env
# 每个房间最大参与人数
MAX_PARTICIPANTS_PER_ROOM=12

# 是否启用录制
ENABLE_RECORDING=false

# 录制文件存储路径
RECORDING_STORAGE_PATH=./recordings
```

## 常见问题

### 1. CORS 错误
**问题：** 前端访问 SFU 服务器时提示跨域错误

**解决：**
- 检查 `CORS_ORIGINS` 是否包含前端实际地址
- 确保使用 JSON 数组格式：`["https://..."]`
- 重启 SFU 服务器

### 2. JWT 验证失败
**问题：** 提示 "Invalid token" 或 "Token expired"

**解决：**
- 确保 `JWT_SECRET_KEY` 与后端 .NET API 一致
- 检查 `JWT_ISSUER` 是否为 `yinzhixin-healthcare`
- 检查 token 是否过期（`JWT_TTL_SECONDS`）

### 3. Redis 连接失败
**问题：** SFU 服务器启动失败，提示 Redis 连接错误

**解决：**
- 检查 `REDIS_HOST` 和 `REDIS_PORT` 是否正确
- 确认 Redis 服务已启动
- 如果有密码，配置 `REDIS_PASSWORD`

## 启动服务器

配置完成后，启动 SFU 服务器：

```bash
# 开发环境
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 生产环境（使用 HTTPS）
python start_https.py
```
